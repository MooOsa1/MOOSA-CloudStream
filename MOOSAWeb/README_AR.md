# MOOSA Web — النسخة الأولى

موقع مستقل عن إضافة **MOOSA Hub**، بتصميم عربي للكمبيوتر والتلفزيون والجوال، مع مشغل فيديو داخل الموقع.

## ما الذي يعمل؟

- تصفح الأفلام والمسلسلات من TMDB بنتائج حقيقية، مع بحث وتصنيفات وترتيب وبلد إنتاج، **واختيار الموسم والحلقة داخل صفحة المسلسل**.
- صفحة تفاصيل لكل عنوان، وصور وتقييمات، وقائمة «المفضلة» محفوظة على جهازك.
- مشغل HTML5 يدعم MP4 وWebM وHLS عندما يدعم المتصفح وصاحب المصدر ذلك.
- اختيار جودة HLS المتاحة، وترجمات عربية وإنجليزية SRT/VTT، وإضافة ترجمة محلية وتعديل توقيتها ±15 ثانية.
- فيديو تجريبي حر للاختبار، وكذلك فتح فيديو محلي من جهازك.

**مهم:** وجود فيلم في TMDB **ليس دليلًا على وجود سيرفر مشاهدة**. لا تُسحب سيرفرات CloudStream تلقائيًا؛ المتصفح له قيود مختلفة، ويجب استخدام روابط فيديو مخوّل لك تشغيلها.

## تشغيل الموقع على الكمبيوتر

1. ثبت Node.js الإصدار 20 أو أحدث.
2. افتح مجلد `MOOSAWeb` في Terminal.
3. انسخ `.env.example` إلى `.env`.
4. أضف مفتاح TMDB في المتغير `TMDB_API_KEY`، أو استخدم `TMDB_READ_ACCESS_TOKEN`.
5. شغّل:

```bash
node --env-file=.env server.mjs
```

6. افتح `http://localhost:3000`.

**ملاحظة:** الكود لا يحتاج `npm install`. الاختبارات تعمل عبر `npm run check`.

## تشغيل فيلم من مصدر قانوني

يمكنك لصق رابط فيديو آمن `https://...mp4` أو `https://...m3u8` في المشغل. لإضافة مصادر لعنوان معين عدّل `data/streams.json`؛ اسم المفتاح `movie:رقم_TMDB` أو `tv:رقم_TMDB`، ولتشغيل حلقة محددة استخدم `tv:رقم_TMDB:رقم_الموسم:رقم_الحلقة`؛ كل حلقة تتطلب رابطها الخاص حتى ما تنفتح حلقة أخرى بالغلط. يتطلب HLS وترجمات المصدر تفعيل CORS على الخادم. المشغل **لا يتجاوز DRM أو حماية المواقع أو صلاحيات المحتوى**.

## تشغيله على الإنترنت

نحتاج استضافة تدعم **Node.js**، ومتغير بيئة لمفتاح TMDB، ورابط HTTPS. رفع الملفات إلى GitHub **لا ينشر الموقع تلقائيًا**، وGitHub Pages وحده لا يستضيف الخادم الذي يتصل بـTMDB. ملف المشروع منفصل عن CloudStream، وبالتالي تطويره لا يغير الإضافة الحالية.


## نشر نسخة MOOSA Web على Render

تم تجهيز ملف `render.yaml` في جذر المستودع، وهو يحدد تشغيل الموقع مستقلاً عن إضافة CloudStream.

1. افتح [لوحة Render](https://dashboard.render.com/) وسجل الدخول.
2. اختر **New → Blueprint** واربط حساب GitHub بمستودع `MooOsa1/MOOSA-CloudStream`.
3. اختر ملف `render.yaml` في الفرع `main`، ثم أدخل مفتاح `TMDB_API_KEY` في خانة المتغير السري عندما يطلبه Render.
4. نفّذ **Apply / Deploy**. سيظهر رابط الموقع في صفحة الخدمة بعد نجاح النشر؛ اختبر المسار `/healthz` للتحقق من عمل الخادم.
5. يتم فحص JavaScript واختبارات الخادم تلقائيًا عند تحديث ملفات الموقع عبر GitHub Actions، وكذلك ضمن أمر بناء Render.

**حدود الخدمة المجانية:** Render يوقف خادم Node المجاني بعد 15 دقيقة من عدم النشاط؛ لذلك قد يستغرق أول فتح لاحق قرابة دقيقة. لمن يريد استجابة سريعة دائمًا، استخدم خطة تشغيل لا تتوقف عند الخمول. لم يتم إنشاء خدمة Render أو حجز دومين أو نشر رابط عام تلقائيًا.

**تنبيه:** مفتاح TMDB يضيف بيانات الأفلام والمسلسلات، لكنه لا يضيف سيرفرات مشاهدة. أضف فقط مصادر التشغيل التي تملك صلاحية استخدامها، مع التأكد من HTTPS وCORS ودعم المتصفح.


## CloudStream Web Bridge (تجريبي)

ميزة اختيارية تربط موقع MOOSA Web بتطبيق CloudStream المثبّت على جهاز **أندرويد/Fire TV**. يدعم الجسر مزوّدي التشغيل المباشرين المثبّتين من مستودع MOOSA أو من مستودعات خارجية، **إذا كانت الإضافة مفعّلة ومتوافقة**. لا يمكن لخادم Render تنفيذ ملفات .cs3 أو Kotlin مباشرة، لذلك تظل جميع الإضافات تعمل محليًا داخل CloudStream، ويرسل التطبيق النتائج إلى الموقع عبر HTTPS بعد الإقران فقط.

### الربط

1. حدّث إضافة **MOOSA Hub** إلى إصدار يدعم **Web Bridge**.
2. افتح [MOOSA Web](https://moosa-web.onrender.com/) واضغط **CloudStream / ربط CloudStream** وأنشئ رمز اقتران.
3. على جهاز أندرويد، افتح **CloudStream → MOOSA Hub → Settings → Web Bridge**، وأدخل الرمز المكوّن من 14 حرفًا ثم Connect. الرمز صالح **10 دقائق**.
4. أبقِ تطبيق CloudStream مفتوحًا ومتصلًا. اضغط Play على فيلم، أو اختر موسمًا وحلقة لمسلسل. عندها فقط يبدأ جلب الروابط؛ لا يتم البحث عند تصفح المكتبة.
5. تظهر المصادر المتاحة بالتدريج، مع تقديم أعلى جودة معلنة، واستبعاد دقات أقل من 720p والأسماء التي تحتوي Download. الإضافات البطيئة أو غير المستجيبة تخضع لمهلة عامة.
6. لفصل الجهاز، اختر Disconnect من إعدادات Web Bridge داخل CloudStream.

### حدود معروفة

- **الإضافات غير المثبتة على جهاز CloudStream لا يمكن استخدامها**، وليس كل نوع من إضافات CloudStream مدعومًا. هذا الإصدار يجرب مزوّدي **DirectProvider** والإضافات المفعّلة التي توفر `loadLinks` بالفعل، لكنه لا يضمن دعم كل إضافة خارجية، ولا يمكنه تشغيل الإضافات داخل المتصفح مباشرة.
- بعض المصادر تتطلب Referer أو Cookies أو DRM أو CORS؛ نجاحها في تطبيق CloudStream **لا يضمن تشغيلها داخل متصفح الويب**. لا يستخدم الجسر تجاوز حماية أو خادمًا عامًا لإعادة بث الفيديو.
- الجودة المعلنة مأخوذة من بيانات مزوّد CloudStream؛ لا تعني وحدها إثبات الدقة الفعلية أو جودة البث المستمر.
- لا يستخدم الجسر سيرفرات أو ترجمات دون تصريح باستخدامها، ولا يرفع كود الإضافات أو ملفات الجلسات إلى Render. لكنه يرسل روابط تشغيل مختارة إلى خدمة MOOSA Web التابعة لك، لذلك لا تربط جهازًا لا تثق به.
- الربط يعتمد على بقاء التطبيق عاملًا وعلى نسخة خادم Render. إعادة تشغيل الخادم قد تلغي طلب البحث الجاري. الرموز المؤقتة والمهام غير المكتملة لا تعود تلقائيًا بعد إعادة التشغيل.
- هذه نسخة بيتا وليست ضمانًا للعمل مع كل المستودعات أو كل المضيفين.
